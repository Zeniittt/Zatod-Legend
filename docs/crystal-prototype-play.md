# Hướng dẫn prototype đã chuyển tên

Hướng dẫn hiện hành: [Chơi thử Zatod Legend](zatod-prototype-play.md). Scene `ZatodPrototype.unity`, menu **GameEditor > Open**, scripts `Start-ZatodServer.ps1` / `Start-ZatodClient.ps1`. Các script Start-Crystal cũ chỉ là wrapper tương thích. Tài liệu báo cáo Crystal trong thư mục này giữ vai trò nguồn tham chiếu/lịch sử.
