# Pre-D35 replay fixtures

Generated on 24 November 2026 by compiling Heroes/Combat source read from Git commit `3d774252d`, before adding Evo simulation. Each of the 25 baseline Heroes fights another baseline Hero at level 80, five stars, Blue, all three skills level 80. Seed is `31415 + roster index`; no live account, server or Unity scene is used.

These are newly generated baseline goldens, not the historical network recordings from 19 November (those remain optional local evidence). Each compressed file contains its complete old rules/config snapshot, commands, terminal tick, winner and digest. CrystalChecks resimulates every file and compares the recorded outcome. Do not regenerate goldens from changed simulation code to make a regression pass.
